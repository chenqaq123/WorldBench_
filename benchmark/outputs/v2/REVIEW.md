# WorldLine Core v2 修复结果

112 / 112 个基础 case 已生成并通过集合校验；112 个实验签名及公开 prompt 均唯一。25 项离线回归测试通过。完整分布与校验结果见 [validation.report.json](validation.report.json)，样本入口见 [core_matrix.manifest.json](core_matrix.manifest.json)。旧版本和各阶段失败尝试保留，未混入本版本。

|项目|修复后的结果|
|---|---|
|规模|7 场景 × 4 task × 3/4 人 × 反打/俯拍，共 112 条；每条 3 shots|
|评分镜头|仅最终全景；开场全景作参照，partial 不评分|
|主评分|全部人物的数量正确、全部人物的位置关系正确；两者同时正确才通过|
|Position Swap|检查交换人物的新位置，同时检查未变化人物的原位置；不在最终 Content 重述座位|
|Entry|明确写出进入并坐到指定座位；新人物的身份参照来自 Shot 2，但 Shot 2 不评分|
|真实素材|6 部作品、14 段有出处的原文；每段对应 8 条 case；原文实际传入 Story Skeleton 阶段|
|人物属性|A/B/C 各为 56 男、56 女；D 为 28 男、28 女；颜色按角色均匀轮换|
|保存内容|Public prompt、内部 episode、布局快照与全景答案、真实来源、完整 LLM 访问及失败尝试记录|

人物位置用“主体身份 → 地标座位”的对应关系表示，不把反打后的画面左右翻转误判为换位。数量正确但人物位置错误会单独显示位置失败；评分对象包括当镜提及的人物，未提及主体只是诊断子集。

真实素材的章节定位、摘录和 SHA-256 见 [素材库](../../sources/catalog.json)，可读的作品与片段索引见 [来源说明](../../sources/README.md)。原作人物、场所和进入/离开/交换事件与实验设定不一致时，后续步骤明确作为改编处理，不将实验事件冒称为原作事实。公开文字仍保持性别、衣服颜色、地标座位和简短对话动作，不加入时长。

查看一个四人位置交换案例：[prompt.txt](WL-CORE-CAFE-SWAP-4P-REV-3S/prompt.txt)、[冻结答案](WL-CORE-CAFE-SWAP-4P-REV-3S/annotations.hidden.json)。最终全景 Content 仅提及 A 的对话动作，但人数和位置评分检查 A/B/C/D 全部主体。

当前完成的是 prompt 构造与文本/结构验证。此处没有将 LLM 审校标为人工复核，也未宣称模板已经通过真实视频验证。人工复核、实际镜头合规性与视频视觉评测仍是后续阶段；其中视觉评测结果可输入已有的数量/位置评分函数。
