# WorldLine v3.1：16 条开发验收样本的文本审阅

这是一轮开发验收，不是正式 benchmark 发布，也不是人工 judge 一致性验证。样本清单在生成前固定，四类任务各 4 条，反打/俯拍、3/4 人、3/4 镜头各 8 条，覆盖 7 个场景。其余 96 条尚未构造。

本轮 assistant 已逐条读取最终公开 prompt。16 条均可进入视频 pilot：开场建立人物与场景；更新仅涉及规定身份；最终镜头只指定全景与反打/俯拍，不提供人物数量、座位占位或固定地标答案；保留未被持续提及的人物；公开文字没有时长。

该结论只表示值得进行可生成性和可评测性试测，不证明自然语言相机一定被执行，也不证明跨视角位置必然可观察。视频失败不会触发换样本或挑选更好的随机种子。

## 构造过程中修复的规则

- 审核把 coffee table 误当成禁止的定位地标。澄清：拍摄对象可以命名，禁止的是最终视角要求列举座位或必须入镜的定位地标。
- 审核仍要求换位句重复原位置。澄清：点名两人 exchange/swap seats 即完整更新，不重复原位置和目标位置。
- 真实素材的故事骨架一度被改写为无关的 holiday trip。强化普通场景改编中的话题连续性；保留改写前产物于 superseded，不冒充最终数据。
- 最后一轮未通过审核时不再付费修复一个无法继续审核的输出。失败和所有已完成阶段仍保留。

## 正式冻结前仍要关注

- 开场相机句较长，仍保留建立初始布局所需的座位描述；不应与已简化的最终镜头混淆。
- Café 的 story / timeline / interrupted point、Meeting 的 consultation / account 等措辞仍偏抽象。它们不改变世界状态答案，但自然性与素材辨识度应在人工 prompt 验收中检查。
- Exit 中 exits the venue 能表达离开，实际视频是否完整执行退出要与相机/观察失败分别记录。
- 对称桌面布局在反打或俯拍下可能无法可靠对应物理位置。不得靠预期人物身份来反推位置，也不得为了增加有效率补写最终答案。

## 费用与证据

开始前 OpenRouter 返回总余额 100 USD、累计使用 89.633086287 USD，可用约 10.3669 USD。16 条构造完成后可用约 9.9787 USD。两次查询的差额包括本轮失败尝试；若账户有并行使用，它也可能包含其他调用。各完成 run 和新失败阶段的 response_metadata 保存 API 返回的费用。

视频设置：Seedance 2.0 Fast，480p，16:9，每镜 3 秒仅用于总时长，3 镜头请求 9 秒、4 镜头请求 12 秒，seed=42，关闭音频。视频与 Sol 单裁判记录在独立 evaluation 目录，不覆盖旧实验。

人工盲标必须使用新版开场参照入口。不能将 assistant 文本审阅、mock 测试或已有 LLM 审核填成真人标注通过。
